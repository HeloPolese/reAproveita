# ♻️ Reaproveita

### Dando um novo destino ao que ainda pode ser aproveitado.

O **Reaproveita** é uma aplicação mobile desenvolvida para conectar pessoas que desejam disponibilizar itens que não utilizam mais a pessoas interessadas em aproveitá-los. A proposta é incentivar a reutilização, reduzir o desperdício e promover uma comunidade mais consciente e colaborativa.

O projeto foi desenvolvido no contexto acadêmico do **Instituto Federal do Espírito Santo (IFES) — Campus Santa Teresa**, como uma iniciativa que une tecnologia, sustentabilidade e impacto social.

---

## 🌱 Sobre o projeto

Muitos produtos e alimentos deixam de ser utilizados e acabam sendo descartados, mesmo quando ainda poderiam ter uma finalidade. O Reaproveita surge como uma alternativa para aproximar quem tem algo disponível de quem pode dar uma nova utilidade a esse item.

Por meio de uma interface simples e intuitiva, a aplicação busca facilitar essa conexão e tornar o reaproveitamento mais acessível.

### 🎯 Objetivos

- ♻️ Incentivar o reaproveitamento de itens e a redução do desperdício.
- 🤝 Conectar pessoas que desejam disponibilizar algo a quem possa aproveitar.
- 🌎 Promover hábitos mais sustentáveis e o consumo consciente.
- 📱 Utilizar a tecnologia para facilitar iniciativas de colaboração entre pessoas.

## ✨ Funcionalidades

A aplicação contempla o fluxo de navegação e interação necessário para apresentar a proposta do sistema.

- **Visualização de itens:** exibição dos itens disponibilizados para reaproveitamento.
- **Cadastro de itens:** interface para inserir informações sobre itens que podem ser disponibilizados.
- **Navegação entre telas:** fluxo de navegação entre as principais áreas da aplicação.
- **Organização das informações:** apresentação dos dados dos itens de maneira clara e acessível.
- **Interface mobile:** experiência desenvolvida para dispositivos móveis, com componentes visuais e interativos.

> **Nota:** o projeto está em desenvolvimento acadêmico. As funcionalidades disponíveis dependem da versão atual do código, e a integração com um backend não está contemplada no protótipo apresentado.

## 🏗️ Arquitetura e organização

O projeto utiliza uma organização por responsabilidades, separando elementos da interface e modelos de dados para facilitar a manutenção e a evolução da aplicação.

Entre os elementos da estrutura estão:

- **Models:** representação dos dados utilizados pela aplicação.
- **Screens:** telas e páginas da interface.
- **Widgets:** componentes visuais reutilizáveis.
- **Navegação:** integração entre as diferentes telas e seus respectivos fluxos.

Essa organização contribui para a legibilidade do código e facilita a implementação de novas funcionalidades.

## 🚀 Como executar o projeto

### Pré-requisitos

Antes de executar a aplicação, certifique-se de ter instalado:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart) — normalmente incluído no Flutter.
- [Visual Studio Code](https://code.visualstudio.com/) ou [Android Studio](https://developer.android.com/studio).
- Um emulador Android ou dispositivo compatível.

### Instalação

**1. Clone o repositório**

```bash
git clone <URL_DO_REPOSITORIO>
```

**2. Acesse a pasta do projeto**

```bash
cd reaproveita
```

**3. Instale as dependências**

```bash
flutter pub get
```

**4. Verifique a configuração do ambiente**

```bash
flutter doctor
```

**5. Execute a aplicação**

```bash
flutter run
```

Certifique-se de que o arquivo `pubspec.yaml` esteja presente na raiz do projeto e de que um dispositivo ou emulador esteja disponível.

## 🌍 Impacto e propósito

O Reaproveita busca mostrar como soluções digitais podem contribuir para práticas mais sustentáveis no cotidiano.

Ao facilitar a conexão entre pessoas, a proposta incentiva a redução do descarte desnecessário, o melhor aproveitamento de recursos e a colaboração dentro da comunidade.

**Mais do que disponibilizar itens, a ideia é transformar o que seria descartado em uma nova oportunidade de uso.**

## 🔮 Possibilidades futuras

Entre as possibilidades de evolução do projeto estão:

- Integração com uma API e um banco de dados.
- Autenticação e gerenciamento de usuários.
- Persistência das informações cadastradas.
- Busca e filtragem de itens por categoria.
- Comunicação entre pessoas interessadas e responsáveis pelos itens.
- Melhorias de acessibilidade e experiência do usuário.

Essas possibilidades representam caminhos para ampliar a aplicação além do protótipo acadêmico.

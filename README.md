# ♻️ Reaproveita — Hackathon IFES Campus Santa Teresa 2026

### Dando um novo destino ao que ainda pode ser aproveitado.

O **Reaproveita** é uma aplicação mobile desenvolvida durante o **Hackathon do Instituto Federal do Espírito Santo (IFES) — Campus Santa Teresa, em 2026**. O projeto busca conectar pessoas que desejam disponibilizar itens que seriam descartados a pessoas interessadas em aproveitá-los, incentivando a reutilização, a redução do desperdício e a colaboração entre pessoas.

A iniciativa une tecnologia, sustentabilidade e impacto social, demonstrando como soluções digitais podem contribuir para um futuro mais consciente.

---

## Sobre o projeto

O Reaproveita surgiu durante o Hackathon 2026 do IFES — Campus Santa Teresa, a partir da observação de um problema presente no próprio ambiente acadêmico: o descarte de alimentos no setor de Agronomia em razão da elevada produtividade agrícola e da existência de excedentes da produção.

Diante dessa realidade, a equipe idealizou uma solução tecnológica para conectar pessoas que possuem alimentos excedentes a pessoas interessadas em adquiri-los ou aproveitá-los. A proposta busca reduzir o desperdício, valorizar a produção agrícola e criar oportunidades de geração de renda a partir de alimentos que poderiam ser descartados.

Desenvolvido como uma aplicação mobile, o Reaproveita transforma uma necessidade observada no campus em uma oportunidade de inovação, unindo tecnologia, sustentabilidade e empreendedorismo para promover um melhor aproveitamento dos recursos disponíveis.

### Objetivos

- Incentivar o reaproveitamento de itens e a redução do desperdício.
- Conectar pessoas que desejam disponibilizar algo a quem possa aproveitar.
- Promover hábitos mais sustentáveis e o consumo consciente.
- Utilizar a tecnologia para facilitar iniciativas de colaboração entre pessoas.

## Funcionalidades

A aplicação contempla o fluxo de navegação e interação necessário para apresentar a proposta do sistema.

- **Visualização de itens:** exibição dos itens disponibilizados para reaproveitamento.
- **Cadastro de itens:** interface para inserir informações sobre itens que podem ser disponibilizados.
- **Navegação entre telas:** fluxo de navegação entre as principais áreas da aplicação.
- **Organização das informações:** apresentação dos dados dos itens de maneira clara e acessível.
- **Interface mobile:** experiência desenvolvida para dispositivos móveis, com componentes visuais e interativos.

> **Nota:** o projeto foi desenvolvido no contexto do hackathon e utiliza os recursos implementados na versão atual. A integração com um backend poderá ser considerada em futuras evoluções.

## Como executar o projeto

### Pré-requisitos

Antes de executar a aplicação, certifique-se de ter instalado:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart) — normalmente incluído no Flutter.
- [Visual Studio Code](https://code.visualstudio.com/) ou [Android Studio](https://developer.android.com/studio).
- Um emulador Android ou dispositivo compatível.

### Instalação

**1. Clone o repositório**

```bash
git clone <URL_DO_REPOSITORIO>
```

**2. Acesse a pasta do projeto**

```bash
cd reaproveita
```

**3. Instale as dependências**

```bash
flutter pub get
```

**4. Verifique a configuração do ambiente**

```bash
flutter doctor
```

**5. Execute a aplicação**

```bash
flutter run
```

Certifique-se de que o arquivo `pubspec.yaml` esteja presente na raiz do projeto e de que um dispositivo ou emulador esteja disponível.

## Impacto e propósito

O Reaproveita demonstra como a tecnologia pode ser utilizada para estimular práticas mais sustentáveis no cotidiano. Ao facilitar a conexão entre pessoas, a proposta incentiva a redução do descarte desnecessário, o melhor aproveitamento de recursos e a colaboração dentro da comunidade.

**Mais do que disponibilizar itens, a ideia é transformar o que seria descartado em uma nova oportunidade de uso.**

## Possibilidades futuras

Entre as possibilidades de evolução do projeto estão:

- Integração com uma API e um banco de dados.
- Autenticação e gerenciamento de usuários.
- Persistência das informações cadastradas.
- Comunicação entre pessoas interessadas e responsáveis pelos itens.
